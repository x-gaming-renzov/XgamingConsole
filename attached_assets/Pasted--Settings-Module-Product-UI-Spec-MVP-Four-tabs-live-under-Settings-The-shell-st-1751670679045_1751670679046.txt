### **Settings Module – Product & UI Spec (MVP)**

> Four tabs live under **Settings**. The shell stays consistent; only the content pane swaps.
> Side‑menu → **Profile · Billing · Knowledge Base · Integrations**

---

## 0 · Container Layout

| Region                             | Spec                                                                               |
| ---------------------------------- | ---------------------------------------------------------------------------------- |
| **Left sub‑nav** (within Settings) | 160 px, light background. Active tab highlighted.                                  |
| **Content pane**                   | 960 px max width, centred. Cards  “shadow‑1”, 24 px gutters.                       |
| **Breadcrumb**                     | “Settings / Billing” as h6 above page title for deep‑link clarity.                 |
| **Save**                           | Tabs auto‑save on field blur *except* Billing forms which need CTA **Save & Pay**. |

---

## 1 · **Profile**

### 1.1 Fields

| Section      | Fields & UI                                                                                                                                        |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Account**  | • Photo avatar upload<br>• Display name (text)<br>• Role (read‑only badge Owner / Editor / Developer / Viewer)<br>• Email (read‑only if SSO/OAuth) |
| **Security** | • Password reset button (modal)<br>• Two‑factor toggle (if enabled in backend)                                                                     |
| **Locale**   | • Time zone dropdown (searchable)<br>• Date‑format toggle (DD/MM vs MM/DD)<br>• Language dropdown (EN only for now – greyed)                       |
| **API Key**  | Primary key display → masked; “Copy” button; “Rotate” danger button (confirm modal).                                                               |

### 1.2 Copy

*Top note:* “Profile changes save instantly except password.”
Tooltip on rotate: “Rotating key breaks SDK until updated in code.”

### 1.3 Endpoints

```
GET  /v1/me
PUT  /v1/me               { displayName, timezone }
POST /v1/me/rotate_api_key
POST /v1/me/reset_pw
```

## 2 · **Billing**

*(Credits model)*

### 2.1 Header Summary Card

| Metric            | Display                               |
| ----------------- | ------------------------------------- |
| Remaining Credits | Large 48 px number, units “of 10 000” |
| Est. Days Left    | based on 7‑day avg consumption        |
| Current Plan      | e.g., “Pro · \$199/mo” badge          |

### 2.2 Usage Chart

*Mini area chart – credits used per day (last 30).*

### 2.3 Payment Method

| UI                           | Details                                  |
| ---------------------------- | ---------------------------------------- |
| Card on file (last 4 digits) | “Change” button – Stripe Elements modal. |
| Billing email                | Editable field.                          |

### 2.4 Recharge

* Card grid: +1 000, +5 000, +10 000 credits.
* CTA **Buy Credits** opens confirmation “Pay \$ X via saved card”.
* Post‑success toast & Stripe receipt email.

### 2.5 Endpoints

```
GET  /v1/billing/summary
POST /v1/billing/purchase_credits { qty }
POST /v1/billing/update_payment_intent
```

## 3 · **Knowledge Base**

> Upload internal docs that the PulseFlags LLM can cite when answering PM queries.

### 3.1 Upload Panel

| Field          | UI                                           |
| -------------- | -------------------------------------------- |
| File drop‑zone | Accept PDF, MD, TXT (max 10 MB each).        |
| Category tag   | Optional (e.g., “Tutorial”, “Design Bible”). |
| Visibility     | Org‑wide (default) / Private to me (toggle). |

*Progress bar per upload; server runs text extraction asynchronously.*

### 3.2 Documents Table

| Columns                        | Actions                             |
| ------------------------------ | ----------------------------------- |
| File name (link opens preview) | • Delete (trash) • Re‑tag           |
| Tokens (count)                 |                                     |
| Indexed status                 | badge “Ready / Processing / Failed” |

### 3.3 Limits & Copy

*Banner:* “Up to 100 files or 25 MB total in beta.”
Alert if quota reached; upgrade flag in Billing later.

### 3.4 Endpoints

```
POST /v1/kb/upload
GET  /v1/kb/list
DELETE /v1/kb/{fileId}
PUT  /v1/kb/{fileId}   { tags, visibility }
```

## 4 · **Integrations**

### 4.1 Slack Card (only item for now)

| State             | UI                                                                                            |
| ----------------- | --------------------------------------------------------------------------------------------- |
| **Disconnected**  | Grey card, Slack logo, text “Connect to send live alerts & summaries”. Button **Connect**.    |
| **Auth flow**     | OAuth redirect `https://slack.com/oauth/v2/authorize?client_id=...`                           |
| **Connected**     | Green badge “Connected ✓”, workspace name, channel selector dropdown (populated from scopes). |
| **Event toggles** | • Silent‑push failure (default on)<br>• Experience auto‑rollout<br>• Weekly summary           |
| **Disconnect**    | Danger button bottom.                                                                         |

### 4.2 Endpoints

```
GET  /v1/integrations/slack/status
POST /v1/integrations/slack/connect   (OAuth code)
PUT  /v1/integrations/slack/config     { channel, events[] }
DELETE /v1/integrations/slack
```

### 4.3 Copy

*Tooltip on channel:* “Bot must be invited to channel after connection.”
Banner if scopes insufficient.

## 5 · UX Micro‑Interactions

| Component        | Detail                                                                              |
| ---------------- | ----------------------------------------------------------------------------------- |
| Tabs auto‑scroll | Keep left sub‑nav fixed as user scrolls long tables.                                |
| Toasts           | Uniform component top‑right – success green, error red.                             |
| Form auto‑save   | 500 ms debounce; grey spinner appears inline.                                       |
| Danger actions   | Require `DELETE … TYPE “DELETE”` typed confirmation on API key rotate & doc delete. |

---

## 6 · Accessibility

* All toggle switches have label + aria‑checked.
* Table rows focusable; Delete via `Del` key triggers confirm.
* Colour tokens pass WCAG AA on dark & light modes.
