### **Campaign Details Page — Design & Function Spec (MVP)**

*Route: `/campaigns/{campaignId}` – opens from the **Manage** button in the Campaigns table.*

---

## 1 Page Skeleton

```
Breadcrumb   Campaigns / Q1 Acquisition Push

Header Bar   Name  |  utm_source  |  Status badge (Active / Scheduled / Ended / Paused)
              CTA:  Edit Details  ⋮ dropdown (Pause · Resume · Archive)

Tabs          Overview  ·  Experiences  ·  Schedule  ·  History
```

---

## 2 Tab A – Overview  (default)

| Section                   | Content                                                                                                                      |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **KPI Tiles (4)**         | • **Installs 7 d** (1 247)<br>• **Avg D0 Retention** (58 %)<br>• **Avg D1 Retention** (40 %)<br>• **Revenue 7 d** (\$ 2 450) |
| **Experience Allocation** | Horizontal stacked bar (100 %) shows Control vs each Experience’s % share. Hover tooltip. **Edit Split** button.             |
| **Top Segments**          | Chips of highest‑traffic segments that overlap (e.g., *High‑Tier iOS* 42 % of installs).                                     |
| **Bound Objects**         | Count and list of objects currently modified by any Experience in this campaign (link to object page).                       |

---

## 3 Tab B – Experiences

Table of all Experiences tied to this campaign:

| Experience          | Segment / Audience | Split % | Uplift (Δ D1) | Status      | Actions          |
| ------------------- | ------------------ | ------- | ------------- | ----------- | ---------------- |
| Enhanced Onboarding | All players        | 50 %    | +4.1 %        | Active      | **Adjust Split** |
| VIP Tutorial        | High‑Tier iOS      | 70 %    | +6.0 %        | Rolling out | View             |

*Row click opens Experience drawer.*
Bulk select → **Pause / Resume / Archive**.

---

## 4 Tab C – Schedule

| Card                         | Details                                                     |
| ---------------------------- | ----------------------------------------------------------- |
| **Current Window**           | Start date · End date (optional). Status timeline w/ icons. |
| **Change Schedule**          | Date‑time pickers (UTC converted to local TZ).              |
| **Auto‑End Rule** (optional) | “End campaign when installs > 50 k” toggle.                 |

*Save → updates backend; warning if start date in past becomes immediate.*

---

## 5 Tab D – History

Vertical timeline similar to Experience history:

| Date         | Event                                 |
| ------------ | ------------------------------------- |
| 10 Jul 09:00 | Split changed: VIP Tutorial 25 → 50 % |
| 05 Jul 09:00 | Campaign started (Scheduled)          |
| 01 Jul 15:22 | Campaign created                      |

---

## 6 Interactions & Actions

| Status        | Allowed actions                                                       |
| ------------- | --------------------------------------------------------------------- |
| **Active**    | Edit Details, Adjust Split, Pause, Archive (only if no active split). |
| **Scheduled** | Edit Schedule, Cancel Schedule.                                       |
| **Paused**    | Resume, Adjust Split, Archive.                                        |
| **Ended**     | Duplicate Campaign (prep new dates).                                  |

**Edit Details modal**: change *Label*, *utm\_source*, *icon upload*.

**Adjust Split modal**: identical table to wizard step – per‑segment sliders, Equalize, Copy split.

---

## 7 API Additions

```
GET  /v1/campaigns/{id}/detail   // metrics, experiences, schedule
PUT  /v1/campaigns/{id}          { label, icon, status }
PUT  /v1/campaigns/{id}/split    { experienceId, segmentId?, split }
PUT  /v1/campaigns/{id}/schedule { startAt, endAt }
POST /v1/campaigns/{id}/pause
POST /v1/campaigns/{id}/resume
```

## 9 Design Details

* KPI tiles use same card style (240 × 120).
* Allocation bar colored by Experience accent colors; control is grey.
* Tabs appear only if user has permission; Metrics sparkline on hover.
* When no Experiences: empty state → “No experiences yet. Create one to optimise this campaign.” CTA to wizard pre‑filled.
