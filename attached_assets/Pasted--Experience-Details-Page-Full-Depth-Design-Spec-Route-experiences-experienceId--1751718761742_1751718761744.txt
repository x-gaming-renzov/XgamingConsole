### **Experience Details Page — Full‑Depth Design Spec**

> **Route:** `/experiences/{experienceId}`
> Replaces the current lightweight popup.
> Dark‑theme, 12‑col grid, max‑width 1200 px.

---

## 1 · High‑level IA

```
Header bar
   ├─ Breadcrumb      (Experiences / TikTok Level‑5 Boost)
   ├─ Status badge    (Active · Draft · Rolling out · Completed · Paused)
   └─ Primary action  (contextual: Roll‑out Winner / Resume / Duplicate / …)

Content pane – 4 tabs
   Overview   ·   Variants   ·   Performance   ·   History
```

Each tab scrolls independently; header stays pinned.

---

## 2 · Header Bar

| Unit                 | Spec                                                                                              |
| -------------------- | ------------------------------------------------------------------------------------------------- |
| **Experience name**  | Editable inline (Owner & Editor roles).                                                           |
| **Status badge**     | Colors: Draft (white) · Active (green) · Rolling out (blue) · Completed (grey) · Paused (yellow). |
| **Actions dropdown** | Depends on status (see §6).                                                                       |
| **Breadcrumb**       | “Experiences” links back to list.                                                                 |

*If Rolling out*: progress chip “75 % complete” accompanies badge.

---

## 3 · Tab: Overview

| Section                     | Content                                                                                                                                                                                    |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Summary tiles** (4×)      | • *Uplift* (+4.2 %) – rolling 7 d<br>• *Participants* (9 742)<br>• *D1 Retention* (40 %)<br>• *Activation* (65 %)                                                                          |
| **Campaign & Target Panel** | Card lists each campaign / segment row:<br>`Campaign` · `Segment` · `Experience %` · `Control %` · `Users 7d`.<br>Chip on rows if auto‑rollout enabled. **Edit Split** button opens modal. |
| **Object List panel**       | Table of objects used → click jumps to Variants tab anchor.                                                                                                                                |
| **Schedule / Auto‑roll**    | *Starts:* 08 Jul 09:00 UTC · *Ends:* None.<br>If auto‑roll: rule statement “Convert to 100 % if D1 uplift ≥ 5 % after 5 k users.”                                                          |

---

## 4 · Tab: Variants

Accordion per object (expanded if only one):

\| Header | “Welcome Popup – 1 variant” |
\| Body table |

| Param key      | Control value | Variant A         |
| -------------- | ------------- | ----------------- |
| `title_text`   | “Welcome”     | “Claim your gift” |
| `show_rewards` | true          | false             |

Buttons bottom:

* **Add Variant** (max 3)
* **Duplicate Variant** (quick copy)
* **Save Changes** (disabled if no edits)

Changes here create a new *draft* revision (history tracked).

## 6 · Allowed Actions by Status

| Status          | Primary button   | Secondary               | Bulk menu |
| --------------- | ---------------- | ----------------------- | --------- |
| **Draft**       | *Launch*         | Duplicate · Delete      | —         |
| **Active**      | *Adjust Split*   | Roll‑out Winner · Pause | —         |
| **Rolling out** | *Pause Roll‑out* | View Progress           | —         |
| **Paused**      | *Resume*         | Adjust Split            | —         |
| **Completed**   | *Duplicate*      | Archive                 | —         |

*Roll‑out Winner* sets all splits to 100 % instantly.

---

## 7 · Empty / Error States

| Scenario                     | UI                                                                                       |
| ---------------------------- | ---------------------------------------------------------------------------------------- |
| No metrics yet               | Grey chart placeholder “Experience needs ≥ 100 users before stats appear.”               |
| Object removed from manifest | Red alert banner: “Welcome Popup not present in latest build; players may see fallback.” |

---

## 8 · API Requirements

```
GET  /v1/experiences/{id}
      → includes tabs data blocks (summary, target, objects, schedule)
GET  /v1/experiences/{id}/metrics?metric=d1_retention&period=14d
GET  /v1/experiences/{id}/history
PUT  /v1/experiences/{id}/split      { campaignId, segmentId?, split }
POST /v1/experiences/{id}/variants   (create or update)
POST /v1/experiences/{id}/rollout_winner
POST /v1/experiences/{id}/pause
POST /v1/experiences/{id}/resume
POST /v1/experiences/{id}/archive
```

---

## 9 · Design Details

* Tabs as pill nav below header; active pill accent‑green, inactive grey.
* Chart uses violet line for control, blue/green lines for variants; auto legend.
* Summary tiles animate count change every refresh (fade 300 ms).
* Edit Split modal re‑uses same table component from wizard step.
