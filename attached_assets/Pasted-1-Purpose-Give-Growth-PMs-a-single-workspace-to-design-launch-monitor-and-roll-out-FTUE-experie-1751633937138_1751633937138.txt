1 · Purpose
Give Growth PMs a single workspace to design, launch, monitor, and roll-out FTUE experiences that are:

Bound to campaigns (UTM / ad-group traffic streams).

Built from flagged objects (level parameters, UI components, feature flags).

Measured on Day-0 / Day-1 retention & activation.

The console must let a PM complete the loop below without leaving the browser or needing a developer once the SDK is live.

2 · Target Users & Top-Level Jobs-to-Be-Done
Role (primary)	JTBD phrased in first-person
Growth / Product Manager	1) “Spot which acquisition campaigns under-perform on D1.”
2) “Create a new onboarding experience for that campaign in <10 mins.”
3) “Roll the winner to 100 % when I’m confident.”
Technical PM / LiveOps Designer (secondary)	“Define new level parameters or popup copy as object flags.”
Engineer (integrator)	“Verify SDK traffic and push new manifest when objects change.”

4 · Screen-by-Screen Journey
4.1 Dashboard (/dashboard)
Zone	Component & Behaviour
Metric tiles (4)	Active Experiences · Avg D0 Retention · Avg D1 Retention · Activation Rate
Pulls /metrics/overview.
Alert strip	If any campaign D1 < project avg − 3 pp ⇒ yellow banner “Campaigns need attention → View Campaigns”.
Recent Experiences	Table (☑ hide if empty): Name · Campaign · Object · Uplift · Status. Row-click opens Drawer.
Empty state	“No experiences yet — create your first FTUE experience to optimise onboarding.” CTA ➜ wizard.

Primary CTA (top-bar): New Experience.

4.2 Campaigns (/campaigns)
Section	Functionality
Header metrics	Est. Revenue · Total Installs · Avg D0 Retention · Objects Bound.
Search / filter	Fuzzy by utm_source, utm_campaign, label, or status.
Table columns	Campaign · Installs · D0 Retention badge (High / Normal / Low) · Revenue · Flag Bundle (blue pill) · Allocation % · Manage button.
Row actions	Manage Bundle → Drawer (edit bundle, adjust split, unbind).
New Campaign	Blue CTA opens modal (enter utm_source, optional label).

4.3 Objects (/objects)
UI	Details
Table	Object · Type (Level / Popup / Param) · Flags count · Last used.
Hover	Action: Create Experience pre-selects object & prompts to pick campaign.
Sync banner	Manifest version & “Stale” warning if >7 days old.

4.4 Experiences (/experiences)
Component	Details
Table	Name · Campaign · Object · Uplift · Status.
Status chips: Draft · Active · Rolling out · Completed · Paused.
Bulk ops	Pause / Resume / Archive.
Row-click Drawer	Summary stats + mini line chart (metric dropdown).
Buttons: Adjust Split, Roll-out Winner, End Experience, Duplicate.

4.5 New Experience Wizard (/experiences/new)
Step	Key Fields & Options
1 Select Object	Dropdown (grouped). Auto-populate from manifest.
Preview panel shows current default values.
2 Define Variants	Dynamic form per flag type (text/number/boolean).
Two variants default; “Add Variant” optional.
3 Choose Campaign	Radio:
① Pick existing campaign.
② Quick campaign builder → enter utm_source, slider for rollout %. Live traffic preview.
4 Review & Launch	Summary card; slider to set control vs variants split.
Launch hits POST /experiences, status = Active unless SDK traffic not yet seen (then Waiting).

4.6 Insights (/insights)
Leaderboard widget – Top 5 experiences by uplift.

Campaign health grid – Campaign vs D1 delta heat-map.

Ideas panel – Static suggestions (Phase 1) → AI suggestions later.

4.7 Team / Settings
Team invites with role: Owner · Editor · Viewer · Developer.

Settings shows API key, manifest history, credit usage.
