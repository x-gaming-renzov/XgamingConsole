## 4 Personalizations List Table

### Columns

\| Name | Object | Cohort | Uplift | Status |

```tsx
<DataTable columns={[
```

## 5 Roll-out flow

*One modal, one API call.*

1. **`RolloutModal.tsx`**

   ```tsx
   <Slider min={0.25} max={1} step={0.05} value={pct} onChange={setPct}/>
   <Button onClick={() => api.updateAllocation(id, pct)}>Confirm</Button>
   ```

2. **Backend**: `PUT /admin/flags/{id}` body:

   ```json
   { "allocations": { "variantA": 1.0, "variantB": 0.0 } }
   ```

## 6 Objects & Cohorts pages (MVP scaffolds)

*Objects* – table of flagged objects from manifest:

\| Object | Type | Last used in personalization |

*Endpoint:* `GET /objects` returns id, label, type.

*Cohorts* – saved segments:

\| Cohort | Rules | Created by | Used in |

*Endpoint:* `GET /cohorts`.

Both pages reuse `DataTable` component; creation forms can be punted to later—PMs can pick default cohorts in wizard for now.
