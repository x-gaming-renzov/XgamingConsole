Below is a **detailed spec for the new “Object Details” page** that opens when a PM clicks any row in the Objects list.

It shows *what the object is, how it can be personalised, where it’s already used,* and offers quick actions.
Everything fits the current dark theme and re‑uses existing drawer / card components.

---

## 1 · Navigation & Routing

* Clicking the object name row (anywhere, not just **Create Experience**) opens **`/objects/{objectId}`**.
* The Objects list now has a link cursor on the row; the “Create Experience” button remains as a shortcut.

Breadcrumb shown at top of detail page:

```
Objects / Level 5 Tutorial
```

---

## 2 · Page Layout

```
┌─────────────────────────────────────────────────────────────────┐
│ Header:  Level 5 Tutorial      [Level] badge   Last sync 1 h   │
│ Sub‑text: “Level parameters, rewards, difficulty tuning”       │
│ CTA right:  + New Experience                                    │
└─────────────────────────────────────────────────────────────────┘

Tabs:  Overview · Parameters · Usage · History
```

### 2.1 **Overview** (default tab)

| Section                  | Content                                                                                                                                                                     |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Summary Tiles** (4‑up) | • Variants defined — **3**<br>• Experiences using — **2 active / 1 draft**<br>• Players affected last 7 d — **48 k** (from BigQuery)<br>• Last modified — **10 Jul 14:21**  |
| **Description card**     | Allow PM to edit friendly description (textarea 300 chars, auto‑save).                                                                                                      |
| **Quick Actions card**   | • **Create Experience** (pre‑select this object)<br>• **Duplicate Object** (prep for copy‑as‑new ID; disabled if not supported)<br>• **Archive Object** (only if not used). |

### 2.2 **Parameters** (Flags)

Table columns:

| Parameter (key)  | Type    | Default | Min | Max | Description         |
| ---------------- | ------- | ------- | --- | --- | ------------------- |
| `starting_coins` | integer | 100     | —   | —   | Initial coins given |
| `enemy_count`    | integer | 5       | 1   | 20  | Enemies in level    |

* Each row has copy‑icon for key.
* Control and Variant values preview toggled via “Show current Variant Values” switch (requests most recent active Experience config and overlays the variant column).
* Read‑only for now; future inline edit greyed.

### 2.3 **Usage**

| Table             | Columns                                                                            |
| ----------------- | ---------------------------------------------------------------------------------- |
| Experiences table | Name · Campaign · Status badge · Variant(s) in this object · Split % · Launch date |

*Row click opens Experience drawer in new tab.*
Filter pill “Active / Completed / Draft”.

### 2.4 **History**

Vertical timeline component:

```
12 Jul 09:13  Manifest v42  • Added param enemy_speed
07 Jul 14:21  Manifest v40  • Updated default starting_coins 80→100
01 Jul 11:02  Object created (v37)
```

*Change records pulled from manifest diff table; future CTO data pipeline.*

## 3 · Sidebar Drawer (optional quick view)

If you prefer non‑full‑page:

* Clicking row opens right‑side drawer (480 px) with **Overview tab** only; “Open full page” link.

---

## 4 · Actions & Validation

| Action                | Behaviour                                                                                                                                   |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **Create Experience** | Deep‑link into wizard Step 1 with this object pre‑selected.                                                                                 |
| **Archive**           | Confirmation modal → checks `experiences.countActive == 0`; if >0, disable button with tooltip “Cannot archive while experience is active.” |
| **Duplicate**         | Opens modal to enter new object name; POST `/objects/duplicate`.                                                                            |

---

## 5 · API Endpoints

```
GET  /v1/objects/{id}           // returns metadata, params, summary metrics
GET  /v1/objects/{id}/usage     // paginated experiences list
GET  /v1/objects/{id}/history   // manifest change log
POST /v1/objects/{id}/archive
POST /v1/objects/{id}/duplicate { newName }
```

### Sample object payload

```jsonc
{
  "objectId": "level_5",
  "name": "Level 5 Tutorial",
  "type": "level",
  "description": "Level parameters, rewards, difficulty",
  "params": [
    { "key":"starting_coins","type":"int","default":100,"min":50,"max":200,"desc":"Initial coins" },
    { "key":"enemy_count","type":"int","default":5,"min":1,"max":20,"desc":"Enemies in level" }
  ],
  "stats": {
    "variants": 3,
    "usedByExperiences": 3,
    "players7d": 48102,
    "lastModified": "2025‑07‑10T14:21:00Z"
  }
}
```
